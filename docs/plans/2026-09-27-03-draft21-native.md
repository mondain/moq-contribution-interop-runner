# Draft 21 Native QUIC Implementation Plan

Status (2026-10-01): partially implemented. Draft-21 evaluators and scenarios exist; all 173 required rows have executable bindings (static gate passes). Steps remain unchecked until the static completeness gate passes.

Backend update (2026-10-01): picoquic is the sole supported backend and local
test peer. Quiche options, dependencies, legacy sources, and parity targets
have been retired; quiche references below describe the earlier migration.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an independently audited draft-21 native-QUIC validator without treating draft 18 as the default for unchanged-looking behavior.

**Architecture:** A checked-in delta inventory links every draft-21 requirement and wire element to a fresh draft-21 type, an explicitly proven shared primitive, or a nonapplicability decision. Draft-21 sessions reuse transport interfaces and evidence types, not draft-18 messages or state.

**Tech Stack:** C++20, CMake, quiche C API, GoogleTest, libFuzzer, SQLite3

**Spec:** `docs/moq-contribution-interop-runner-design.md`

## Global Constraints

- Read `docs/draft-ietf-moq-transport-21.txt` first and cite it in every golden-test group.
- No `is_draft18_or_later` protocol behavior or draft-18 message aliases.
- Shared primitives require byte-identical golden vectors in both draft suites.
- Draft-21 results and denominators remain separate from draft 18.
- Optional unsupported filters reduce capability breadth but do not alone fail conformance.

## Review Focus

- Legacy `PUBLISH_OK` type `0x1e` must be rejected where draft 21 reserves it.
- Zero-length filter updates must remove state rather than decode as an empty range.
- Nested `FILL_PARAMETERS` scope must not leak into subscription state.
- Outstanding update counts must decrement on each permitted response form.
- A draft-18 ALPN connection must never enter a draft-21 run.
