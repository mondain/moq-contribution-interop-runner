# Foundation and Requirement Inventory Implementation Plan

Backend update (2026-10-01): picoquic is the sole supported backend and local
test peer. Quiche options, dependencies, legacy sources, and parity targets
have been retired; quiche references below describe the earlier migration.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Docker-runnable C++20 service that inventories both draft corpora, scores persisted requirement outcomes, and exposes empty-run results over HTTP before MOQT networking is added.

**Architecture:** Keep draft source, requirement classification, scoring, persistence, and presentation independent. The executable loads immutable JSON catalogs tied to draft SHA-256 digests, stores runs in SQLite, and serves versioned JSON plus accessible HTML through cpp-httplib.

**Tech Stack:** C++20, CMake, nlohmann/json 3.12.0, cpp-httplib 0.20.0, SQLite3, GoogleTest 1.17.0, Docker

**Spec:** `docs/moq-contribution-interop-runner-design.md`

## Global Constraints

- The checked-in draft 18 and 21 text files are the only protocol authority.
- Do not copy MOQT code, constants, fixtures, or expected bytes from any publisher or relay.
- Keep draft scores independent and list every classified normative statement.
- Use weights 10 for required, 3 for recommended, and 1 for optional statements.
- Bind plain HTTP to `127.0.0.1:8080` by default and `0.0.0.0:8080` in Docker.
- No downstream subscriber service, media-format validation, or production-relay behavior.

## Review Focus

- A draft file changes without a matching catalog update: startup and tests must reject the digest mismatch.
- A normative-keyword occurrence is omitted or classified twice: the catalog audit must fail with its source line.
- A run contains only `NOT_TESTABLE` rows: score denominators must remain zero without division errors.
- SQLite is interrupted while finalizing a run: outcomes and evidence references must commit atomically.
- Untrusted strings reach HTML: report rendering must escape markup and preserve text labels independent of color.
