# Draft 18 Native QUIC Implementation Plan

Backend update (2026-10-01): picoquic is the sole supported backend and local
test peer. Quiche options, dependencies, legacy sources, and parity targets
have been retired; quiche references below describe the earlier migration.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce a native-QUIC draft-18 relay-side validator with complete golden codecs, publisher session state, executable scenarios, and scored evidence.

**Architecture:** quiche is isolated behind a transport interface. Draft-18 owns every MOQT constant and type; incremental session processing emits immutable events consumed by scenarios and evaluators.

**Tech Stack:** C++20, CMake, quiche C API at pinned revision `bbfe6205b8af2e6fadbb6d7818de463fbe123342` (quiche 0.24.9), GoogleTest, libFuzzer, SQLite3

**Spec:** `docs/moq-contribution-interop-runner-design.md`

## Global Constraints

- Read `docs/draft-ietf-moq-transport-18.txt` before each protocol task.
- Derive all expected bytes from the draft; do not inspect client codecs or fixtures.
- Keep quiche types out of MOQT public interfaces.
- Apply receive limits before allocation and record raw deframed bytes before evaluation.
- A draft-18 row is scored only when every scenario context named by its evaluator completes.

## Review Focus

- A frame split at any byte boundary must decode exactly once after completion.
- Two frames in one read must not discard trailing bytes.
- A request message on the wrong stream must produce the draft-prescribed error.
- Forward zero must suppress object delivery without consuming queued source state.
- FIN, RESET_STREAM, and STOP_SENDING races must produce one terminal request outcome.
